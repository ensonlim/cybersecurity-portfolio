### Module 4 : Protecting the Organisation 
- Many organisations rely on cybersecurity professionals to ensure that the right policies and procedures are in place to prevent a cyber attack.
-  Firewalls look deeper into a network traffic and identify malicious behaviour that has to be blocked. Firewalls can have complicated security policies applied to the traffic that is passing through them.
-  There are multiple different types of firewalls like network layer firewall, transport layer firewall, application layer firewall and many other. Different types of firewall serves different purpose.
- A Intrusion prevention system (IPS) uses a set of traffic signatures that match and block malicious traffic and attack.
- If a port scan reports an 'open' state response, the service can be accessed by other network and can be exploited by an attacker.
- A Intrusion Detection system (IDS) is suppose to detect any malicious traffic and create an alert for a network administrator and will not take any action
- There are multiple steps a organisation can take to prevent cyber attack. For instance, doing a background check on employees before hiring them.
- A Honeypor is a behaviour-based detection tool that lures attackers by appealing to their predicted pattern of malicious behaviour. Once a attacker is inside a honeypot, the network administrator can capture, log and analyse their behaviour so that they can build a better defense.
- NetFlow is used to gather information about data flowing through the network, this includes who and what devices are in the network, and when and how users and devices access the network.
